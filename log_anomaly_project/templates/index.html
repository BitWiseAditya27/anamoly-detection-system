How detection works

Feature extraction
Log level, message length, keywords, rarity of message pattern, event bursts, off-hours timing.
Isolation Forest
Selected after comparing against LOF and One-Class SVM on a labeled evaluation set (F1 ≈ 0.81, ROC-AUC ≈ 0.99).
Unsupervised scoring
No manual rules or blacklists — the model learns what "normal" looks like and flags deviations.
Explainability
Each flagged line shows which features drove the decision, so results aren't a black box.
